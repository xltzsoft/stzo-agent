STZO Agent

AI 编程助手，桌面应用和命令行两种用法。登录即用 Claude 等模型，按量计费，余额不足时直接在应用里充值。

桌面应用

下载安装包后即可使用，无需 Node.js：GitHub Releases

macOS 首次打开请在访达里右键应用 →「打开」；Windows 出现 SmartScreen 时点「更多信息 → 仍要运行」。

1. 命令行安装

curl -fsSL https://gc.stzo.cn/agent/install.sh | bash
irm https://gc.stzo.cn/agent/install.ps1 | iex

需要 Node.js 22.19 或更高版本。也可从 GitHub Releases 下载 tgz 后执行 npm i -g 文件名.tgz。

2. 登录

stzo login

浏览器会打开授权页，用 gc.stzo.cn 账号确认即可（没有账号先 注册）。

3. 开始使用

cd 你的项目
stzo

常用命令

/stzo账户菜单：登录、余额、充值、兑换、退出
/recharge查看充值卡并跳转发卡网购买
/redeem <兑换码>在终端里直接兑换 CDK
/model切换模型
/plan只读规划模式：先分析、出计划，再动手
/update立即更新（默认后台自动更新）

内置插件

规划模式/plan，只读探索并生成步骤
子代理scout / planner / worker / reviewer 并行协作
待办模型自己维护任务清单，/todos 查看
危险操作确认rm -rf、强推等命令先问你
受保护路径.env、.git 等不被改写
完成通知任务完成时桌面提醒
